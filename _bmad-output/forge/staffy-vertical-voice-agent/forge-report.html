Staffy

Универсальная multi-tenant платформа управляемых голосовых и текстовых AI-сотрудников, глубоко интегрированных в процессы бизнеса без отдельного ядра для каждого клиента.

Решение

Каналы→ AI-сотрудник Staffy→ Права и действия→ Системы бизнеса

Staffy владеет конфигурацией сотрудников, разговорным и task-контекстом, полномочиями, reusable capabilities/connectors, изменяющими операциями, аудитом и качеством. CRM, ABCP, 1С, телефония, платежи и human inbox остаются системами своих данных.

Продуктовые locks

  • Один AI-сотрудник — одна роль и единый контекст во всех каналах.
  • Свободный сложный диалог; исполнение только через разрешённые typed actions.
  • Assisted setup сейчас, self-service после доказанной повторяемости.
  • Bring your own inbox; при отсутствии — Staffy Inbox.
  • Один активный владелец ответа: бот или человек.

Минимальная техника

  • Go — основной язык core и realtime runtime.
  • Voice/media/inbox — сменные компоненты.
  • Action Executor — модуль Go-приложения.
  • Operations — одна append-only таблица для mutating actions.
  • Конфигурация — immutable hash + eval gate + rollback.

Два reference domain pack

Автозапчасти / ОлегNovofon + Yandex candidate; подбор и заказ через ABCP; существующий обмен в кастомную 1С; временная проверка перед отправкой поставщику.
Услуги / MontagioКвалификация обращения и структурированная заявка на существующем операционном контуре; тот же Staffy core, другие capabilities и policies.
Платформенный экзаменТретий клиент на готовых pack/connectors запускается без core changes, client fork и программиста максимум за рабочий день настройки.

Каналы сейчас

Web widget, Telegram, MAX, Jivo. Для Олега Jivo остаётся human inbox.

Следом

VK и Avito после account-level tests; Android/iOS через общий Staffy protocol.

Spike

Self-hosted Chatwoot за один день: web, Telegram, handoff, MAX bridge, egress и restore.

Отвергнуто

  • Staffy как агент одной отрасли.
  • Клиентские форки ядра.
  • «Переписывание на 50-м клиенте из-за GIL».
  • Полный собственный SIP/WebRTC/PSTN stack с первого дня.
  • Model + RAG + MCP как гарантия надёжных side effects.
  • Microservices, workflow/vector platform и multi-agent hierarchy «на будущее».

Коммерческая модель

  • Разовый запуск и интеграция.
  • Подписка за активного AI-сотрудника.
  • Фактическое voice/AI usage.
  • Новый reusable connector оценивается отдельно и становится частью Staffy.

Сохранившиеся риски

Novofon↔Yandex SIP/transfer/DTMF/data path; Russian PSTN latency; реальная экономика и качество пилотов; Chatwoot/MAX compatibility и data egress; юридические границы каналов и ПДн. Синтетические тесты не заменяют реальных операций.
