## 4. Что сработало — перенести в Epic 3

1. **BMAD-контур с двумя чекпоинтами на историю.** 16 полных циклов за 10 календарных дней; спека — единственный source of truth, frozen-after-approval; срезоделение Never-клаузами удерживало объём каждого среза (последняя история — 30 файлов +4676).
2. **Append-only + derived-состояния + словари честных слов.** Стержень всех 16 поверхностей: факты immutable, состояния — чистые функции read-time, unknown ≠ ноль; в 2-16 доведён до МАТЕРИАЛЬНОЙ честности — SQL CHECK-пара (deadline_word = 'update_unknown') = (promised_at IS NULL): выдуманный срок структурно невозможен, честность проверяется миграцией, не ревью.
3. **Протокол CI ×3 + sha-pinned merge.** 16/16 merge-точек зелёные; пин головы merge-коммитом исключает подмену между ревью и merge; маркер-тишина ловится по пустому списку runs за минуты (§5-1).
4. **Ревью свежим контекстом + независимая QA-копия + мутационные пробы.** Все Major-классы Epic 2 найдены вне «Dev проверяет сам себя» (2-14 M-1 — прямое доказательство). Пробы мутаций до коммита (ослабление CHECK/гейта краснит зонд) дешевле ревью.

## 5. Что не сработало — инциденты и корни

1. **Инциденты маркера пропуска ×2 (2-2, 2-14).** GitHub гасит push- и pull_request-события по ВСЕМУ сообщению головы ветки. 2-2: голова dcb46d3 несла маркер → CI молчал; закрыто амендом (7d62154, force-push до любых CI-прогонов). 2-14 — двойной: голова 0e16b4a несла маркер, а первый кандидат-фикс 167eb27 ЦИТИРОВАЛ подстроку маркера в тексте-описании инцидента — сообщение-описание само глушит события; закрыто амендом (5cf4b37, force-with-lease, контент ветки не менялся). Корень: маркер глушит пуш целиком, включая описательные цитаты. Протокол закреплён и действует (2-15/2-16 без инцидентов): головы story-веток перед PR — без маркера; урок описывается только словами «маркер пропуска».
2. **Merge-конфликты DEVLOG ×~7** (параллельные записи на main и ветке при живой истории) — закрывались union-мерджами ветки с main (прецеденты 2-7/2-9/2-10/2-11/2-13); содержимого не терялось (append-only объединение), затраты механические. Правило retro-1-6 «story-записи на ветке» соблюдалось; конфликт рождает сам main, куда пишутся записи при push-stop.
3. **gofmt-шум инструмента записи ×3** (2-13 Minor-1; 2-16 step-02 port.go 688 строк; step-03 app-тест 456 строк — whitespace-only диффы целых файлов) и две неточные заявки «gofmt чист» в DEVLOG (97, 98). Корень: правки пробелами против табов HEAD. Противоядие: gofmt -w слайса ТЕМ ЖЕ шагом после каждой правки существующих файлов (retro-1-5 расширен, retro-2-2).
4. **Seed/ID-коллизии миров интеграционных тестов ×4+** (998/999 заняты; 971 commitmentWorld; 975/985 слоты; 64-id пул матрицы 2-14 → matrixSequenceIDs 256). Корень: миры детерминированы seed → membership-конфликты в полном прогоне при изолированно-зелёных тестах; grep по одному генератору упускает соседние миры. Противоядие: свободные слоты + ID-диапазоны семейств; единого регистра нет (retro-2-3).
5. **Искажение вывода bash-инструмента (2-16 QA).** Слой вывода поглощает подряд идущие двухсимвольные «скобка+буква»-последовательности («[has_promise]» читается как «as_promise]»); rg/sed/cat/python-repr искажаются одинаково. Единственный Major-кандидат QA 2-16 оказался артефактом отображения — OpenAPI корректен байт-в-байт; противоядие od -c / байтовый дамп (retro-2-4).
6. **Вне-срезовые CI-флэйки ×2 — закрыты пре-шагами с мутационной верификацией.** profile-audit ordering (1-13): первичная идея tie-breaker audit_id опровергнута живым 50% bootstrap-FAIL (UUIDv7 — millisecond-префикс + 74 random бита, порядок внутри миллисекунды случаен), закрыто resulting_version (причинно монотонен). sequenceIDs-гонка (2-6): мьютекс + живой зонд 8×64 + мутационная верификация (снятие Lock краснит). Паттерн «флэйк закрыт пре-шагом цикла следующей истории» работает и не размывает срезы.
7. **Токен — единственный хрупкий канал.** ≥10 передач открытым текстом, ~8 push-stop'ов, один PAT «ожил» после 401; env-only per-invocation выдержан без исключений. Ревокация владельцем после закрытия чата рекомендована повторно (retro-2-6).
8. **Обрыв сессии с WIP (2-14).** Семантически готовый фикс M-1 уцелел, форматирование повреждено; восстановлен orphan-checkpoint'ом (cf814b0) + gofmt. Протокол работает.
9. **Ресайклы окружения.** bootstrap в фоне умирает (foreground, урок 35-sm, повторён); playwright chromium переустанавливался многократно; PATH go для webServer — абсолютным путём.
