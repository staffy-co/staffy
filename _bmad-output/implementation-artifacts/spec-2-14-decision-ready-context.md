## Intent

**Problem:** Составного decision-ready контекста не существует (AC-блок 1, FR-36): назначенный оператор открывает кейс — секции страницы разрозненны (возражения 2-8, деградации 2-12, «Запрос человека» 2-13, история режимов/владения), но единой сборки «причина + активные Work Items + Conversation Mode + identity/authority assurance + Response Owner + факты раздельно» нет; identity assurance (DeriveAssuranceState, verification.go:258 — уровни none/basic/verified, метод, истечение) на странице кейса не отображается вовсе; факты не показываются таблицей со статусами — conflicting в work.go:24 честно read-time деривация, но не рендерится нигде; provenance/версия факта назначенному не агрегируются. ## Implementation Notes

- Контекст = read-only сборка существующих дериваций: ни одна лестница/гейт 2-1..2-13 не расширяется; материал читается теми же транзакциями чтения (advisory-локи не нужны для GET — согласованный снимок одной транзакции).
- Сводка — единственная запись среза: актёр-владелец staffy (NotOwnerText-дисциплина 2-4); операторские сводные НЕ вводятся (kind один — ai_summary; PRG-форм нет); после acknowledge/возврата владельца сводку пишет новый владелец-staffy новой записью (append-only версионность номером).
- Байт-точность claim-текста — анти-фантазийный зонд (прецедент span-выдержек 2-8): машина НЕ проверяет истинность, машина проверяет СТРУКТУРУ (каждое утверждение = строка сводки ∧ ref или disputed) — честная граница AD-7/AD-8.
- Watermark — серверная истина под локами (запрос его НЕ несёт); staleness — read-time сравнение; stale никогда не мутирует сводку.
- Рекомендация — проекция: слово плана последнего outcome + дедлайн открытого handoff; «оператор выбирает другой шаг» = любая существующая команда (каждая записывается своей дисциплиной); отдельных deviation-слов срез НЕ вводит (честная граница; при необходимости — будущий срез со словарём).
- Обновление контекста — GET-ссылка якорем #decision-context (без JS): позиция СЕКЦИИ сохраняется, точная позиция скролла — нет; push/WebSocket/таймеры — Never (AG-4/AD-14).
- Секция появляется только при наличии материала (открытый handoff или сводка); кейс без них — рендер байт-в-байт прежний (контрольная ветка регресса journeys 2-1..2-13).
