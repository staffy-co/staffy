- (decision) Основная UX-метафора и навигация подтверждены: Staffy — рабочее место AI-сотрудников, не конструктор ботов. До запуска путь ощущается как найм, ввод в должность, испытание и допуск; после запуска роль-адаптивная главная 'Сегодня' ведёт владельца к результатам/рискам/расходам, оператора к очереди решений, настройщика к готовности/изменениям. 'Сотрудники' остаются главным объектом, а prompts/models/tools/MCP/webhooks скрыты в раскрываемом экспертном уровне.
- (decision) Модель setup ownership подтверждена: владелец описывает работу обычным языком, Staffy формирует проверяемый draft; готовые Domain Pack/Connectors настраиваются self-service или совместно с консультантом в одном интерфейсе; credentials вводит уполномоченный клиент в защищённой поверхности, консультант видит состояние, а не секреты; шаг можно делегировать без потери прогресса; неподдерживаемая возможность ведёт в assisted extension, а не изображает готовность. Первые два пилота assisted, целевой готовый pack — запуск без программиста.
- (decision) Подтверждена трёхуровневая status model. Fit до credentials: preliminary fit / fit with conditions / Staffy extension required / no fit now. Фактическое подключение: disconnected / connected awaiting verification / verified / verified with limitations / needs attention; каждое ограничение показывает последствие и fallback. Сотрудник: configuring / blocked questions / ready for trial / in trial / working / working with limitations / paused. Основной UI говорит простыми словами, экспертный уровень раскрывает versions/evidence/technical detail. Oleg account connectors и Montagio Novofon нельзя показывать verified до account-level/controlled evidence.

Если внешний Inbox не обеспечивает обязательные функции, используется минимальная Staffy operator surface; частичная поддержка остаётся human-only/manual fallback. - (decision) Подтверждена основная светлая цветовая система Staffy — «Северный кедр»: canvas #F3F5F2; surface #FFFFFF; text #1E2925; muted #66736D; border #D7DED9; primary #315E4C; on-primary #FFFFFF; success #247A52; warning #B56617; danger #B4424B; info #356C9B; focus #7C4DFF. Семантические значения состояний важнее отраслевого декора; палитра применяется ко всей multi-tenant платформе, а Tenant branding остаётся отдельным ограниченным слоем. Dark mode пока не утверждён.
- (decision) Подтверждены типографика и плотность: единый современный sans-serif с полноценной кириллицей; до отдельной бренд-типографики используется системный стек без сетевой загрузки; крупные спокойные заголовки без рекламной декоративности; tabular numerals для денег, SLA и метрик. Средняя плотность для владельца и настройщика, повышенная только в экспертных операционных представлениях; на мобильном один главный следующий шаг вместо сжатой desktop-панели. Пользовательский переключатель плотности не входит в MVP: плотность определяется ролью и задачей экрана.
- (decision) Dark-mode gate закрыт: Staffy admin/operations MVP поставляется только в светлой теме «Северный кедр»; semantic tokens и компоненты должны оставаться dark-ready, но отдельная тёмная палитра и её полная проверка откладываются до доказанной потребности после пилотов. Защищённое клиентское продолжение получает только ограниченные проверяемые Tenant brand tokens и не копирует автоматически тёмную тему сайта Tenant.
- (decision) Подтверждён визуальный component language: умеренное скругление без игрушечности; основная структура через canvas/surface/border, тени преимущественно у overlays; на экране одна доминирующая primary action, второстепенные действия тише; success/warning/danger никогда не кодируются одним цветом — нужны icon + label + consequence/fallback где применимо. Motion короткий и функциональный, без декоративной анимации в рабочих экранах; поддерживаются keyboard, visible focus, text zoom и reduced motion; touch targets минимум 44×44; destructive/high-stakes actions пространственно отделены и подтверждают точный side effect.
